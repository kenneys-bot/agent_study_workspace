## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in `kenneys-bot/agent_study_workspace`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, with label strings equal to their names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `GLOSSARY.md` at the repo root, plus `docs/adr/`. See `docs/agents/domain.md`.
