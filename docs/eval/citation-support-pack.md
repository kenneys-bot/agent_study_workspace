# 引用支持度人工标注包（T42 / #42）

生成日期：2026-11-13　|　状态：**等待负责人标注**

本文件与 [`labels/citation-support.csv`](../../labels/citation-support.csv) 是**人工标注材料**，不是支持度报告：CSV 的 `label` / `note` 全部为空，在负责人填写并运行计分脚本之前，不得给出任何支持率或宣称 §7 达标。

本包共 **67 条引用** + **9 条无证据/证据不足对照**，覆盖 3 个场景。计划 §7 要求人工抽检 **≥50 条**；未标注/未填写的条目不进入计分分母，脚本会报告实际分母。

## 1. 来源与口径（必须一起读）

| 来源 | 条数 | 说明 |
|---|---:|---|
| live（T37 生产端到端） | 5 | 2 条真实 DeepSeek + BGE 候选答复；索引与创建时间见 §7；这是本包唯一的真实模型输出 |
| replay（test/dev 冻结样本） | 62 | `ReplayLexicalEmbedding` + `DemoReplayResponder`（`mode=replay`）；**抽取式答复，不是模型质量证据**，只用于补足三场景与结构覆盖 |
| 无证据对照 | 9 | no_answer / insufficient_info 样本以空知识调用同一 replay 替身；只检查是否拒答/转人工，不参与引用支持率 |

诚实性边界：

- live 条目只有 5 条、且都在 `lost_card`；另外两个场景的多数条目来自 replay。因此**即使负责人把本包全部标成 SUPPORTED，也不能据此宣称 §7 的模型引用支持度达标**。要用于门槛判定，应在生产上用 ≥50 条 live 候选答复重新抽样。
- replay 答复是“从引用片段抄出节选”，引用支持度会天然偏高；它证明的是包/计分链路可用，不是模型会引用。
- 本包只判断**引用是否支持答复节选**，不评价答复是否切题、是否正确、是否应拒答；后者不是本包的标注对象。
- replay 答复可能带 2 条引用；本包每条答复只取**第 1 条引用**与它生成的答复片段，避免同一答复重复计数，第 2 条引用不在本包内。
- live 答复可能含多条事实；每条引用只与人工挑选的对应答复句配对，未引用的答复句不在该行的判断范围内（完整答复见 `data/eval/citation-support/live-suggestions.json`）。

## 3. 标注规范（负责人填写 CSV 前必读）

只填写 `label` 与 `note` 两列，**不要改** `id` / `scenario` / `query` / `answer_excerpt` / `citation_quote` / `knowledge_title`。

| 标签 | 判定标准 |
|---|---|
| `SUPPORTED` | 引用原文**包含或蕴含**答复节选中使用的关键事实、数字、时限、条件或结论。允许同义改写，但关键要素必须能在引用中找到依据。 |
| `NOT_SUPPORTED` | 答复节选陈述了引用**没有**支持的事实/数字/条件（包括与引用矛盾、引用只覆盖复合陈述的一部分、或把“可能”写成“一定”）。 |
| `UNKNOWN` | 引用与答复节选无关、信息不足、或仅凭给出的片段无法判断；无法判断时**不要猜**，填 `UNKNOWN` 并在 `note` 说明缺什么。 |

硬性要求：

1. **禁止预填**：本 CSV 的 `label`/`note` 必须为空；执行模型不得代填、不得用模型判断冒充人工标注。
2. **只判引用支持**：不判答复是否切题、是否合规、是否应拒答；答复答非所问但引用确实支持该答复节选时，仍应标 `SUPPORTED`。
3. **不要用“引用合法”冒充“引用支持”**：引用来自授权快照、quote 逐字匹配，只说明引用合法；是否支持答复是语义判断。
4. **无证据对照行**（`citation_quote` 为空，`id` 以 `cs-noev-` 开头）不参与支持率；`label` 保持为空。如果系统在应拒答时编造了答复，请在 `note` 里记录事实，供负责人另案处理，不填 `SUPPORTED`。
5. **逐条独立判断**：不要参考其他行，也不要参考生成器的任何提示；`note` 可写理由或缺失条件，可为空。

## 4. 计分命令与输出

```bash
uv run python scripts/score_citation_support.py \
  --labels labels/citation-support.csv
```

脚本只读 CSV：统计已标注引用（分母不含未填写项）、支持率、`UNKNOWN` 比例、分场景统计、Wilson 95% 区间，并按 ≥0.95 门槛给出 `PASS` / `FAIL` / `INSUFFICIENT_SAMPLE`。若一条引用都没标，只打印 `WAITING_FOR_HUMAN` 并以 0 退出，不产生任何分数。
