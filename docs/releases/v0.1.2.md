## 1. 本次发布内容（T41 / #41）

把 T40 的 **R-19 修复真正发到线上**，并补齐部署缺口：

1. **compose 增加常驻 worker**：`deploy/compose.app.yml` 现在同时编排 `api` 与
   `worker`（同一不可变镜像、`python -m bank_assistant.worker`、
   `restart: unless-stopped`、不发布端口、同一仓库外 env 与 data/artifacts 挂载）。
   此前线上只有 API，新建质检会停在 `queued`（R-07）。
2. **worker 存活探针**：新增 `python -m bank_assistant.worker --healthcheck`，
   扫描 `/proc/<pid>/cmdline` 的 argv 并排除探针自身；slim 运行时镜像无需安装
   `pgrep`/`procps`。compose 用它做 liveness，`docker compose up --wait` 因此会
   等 worker 真正就绪。
3. **部署/回滚/校验脚本覆盖 api+worker**：`make deploy` 输出 worker 状态；
   `verify_deployment.sh` 校验 worker 运行/健康/同一镜像/restart/无端口；
   `make release-verify` 对照 `release.json` 的 `deployment.worker_container`；
   `rollback.sh` 回滚段先停 worker、只起 api，恢复段再起 api+worker。
4. **上线 T40 修复**：`inspection-v2:f9740dfe9eb83145` 提示词 + 后端
   `inspections/locator.py`（精确→归一化定位、单条证据失败只降级 finding）。
   本次线上 6 次真实质检的 run diagnostics 里 `prompt_version=inspection-v2`、
   0 条 `EVIDENCE_NOT_LOCATABLE` 降级、0 条 `raw_machine_verdict` 回退。
5. **数据库 schema 与索引不变**：alembic head 仍为 `0011_report_exports`；
   `index_version` 仍为 `idx-20261113T025706Z-f7974a6a`（未重建、未切换指针）。
