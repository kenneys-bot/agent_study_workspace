## 4. 构建、传输与部署命令（实际执行）

在 `ticket/T30` 的干净工作树（HEAD=`59a5869`）执行；脚本见
[`scripts/deploy.sh`](../../scripts/deploy.sh)，入口是 `make deploy`：

```bash
# 0) 前置：工作树干净，服务器已有仓库外 .env.app/.env.pg
git status --porcelain          # 空
git rev-parse HEAD              # 59a586976093b2e9359fec97baec6d2f1ee4d6ad

# 1) 构建不可变镜像（脚本实际调用 buildx；目标平台 linux/amd64）
docker buildx build --platform linux/amd64 --load \
  -f deploy/docker/Dockerfile.api -t bank-assistant:api-59a5869 .

# 2) 传输并校验（脚本内联执行）
docker save bank-assistant:api-59a5869 \
  | ssh my-ubuntu-server "tee /tmp/bank-assistant-image-59a5869.tar | docker load >/dev/null \
      && sha256sum /tmp/bank-assistant-image-59a5869.tar | cut -d' ' -f1"
ssh my-ubuntu-server "docker image inspect --format '{{.Id}}' bank-assistant:api-59a5869"

# 3) 一条命令完成构建/传输/服务器 checkout 对齐/compose up/校验
make deploy
```

`make deploy` 的后续步骤（脚本自动执行）：用 `git bundle` 把服务器
`~/workspace/bank-assistant/repo` 精确重置到 `59a5869` → 同步 compose 到仓库外副本 →
以仓库外 `.env.app` 启动 `deploy/compose.app.yml` → 校验 `/health/live`、`/health/ready`、
回环端口与版本页 SHA，并把上一版写入 `deploy/state.env`。

索引由**已部署镜像**在服务器重建（不重建源码）：

```bash
make deploy-index
# 服务器一次性容器执行 python scripts/index_rebuild.py
# 输出 index_version=idx-20261112T110703Z-2334d03e / calibration sha256 / embedding 模型
```
